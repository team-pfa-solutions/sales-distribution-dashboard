# Sales Distribution Dashboard 📊

This project demonstrates how data analytics can be applied to sales monitoring and strategic decision-making.  
Using **Power BI**, I built an interactive dashboard that tracks total sales, regional contributions, top customers, product performance, and country-level insights.  

---

## 🔍 Project Overview
Businesses often generate large volumes of sales data but struggle to extract meaningful insights.  
This project takes a raw dataset (recreated for practice) and transforms it into a **Sales Distribution Dashboard** to answer key questions such as:
- Which regions contribute most to sales?
- Who are the top customers driving revenue?
- Which products are top-performers and which need improvement?
- What countries offer the greatest growth opportunities?

---

## 📊 Key Insights
- **Total Sales:** 985K across all categories.  
- **Regional Performance:** Export dominates with ~54% of total sales, while Central and South lag behind.  
- **Customer Contribution:** Top 2 customers contributed over 88K in sales.  
- **Product Sales:** Product30, Product41, and Product24 lead, while others underperform.  
- **Country Trends:** India drives 46% of sales, followed by Pakistan (7.9%) and Nigeria (6.7%).  

---

## 📈 Recommendations
1. Strengthen underperforming regions while consolidating export growth.  
2. Focus on customer retention while diversifying acquisition.  
3. Optimize product portfolio — promote high-performers, reassess low-sellers.  
4. Expand in high-growth markets like India while building entry strategies for smaller markets.
